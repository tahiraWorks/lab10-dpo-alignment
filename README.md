# Lab 10: DPO Alignment Experiment

Investigates how Direct Preference Optimization (DPO) changes the behaviour of
Qwen/Qwen2.5-0.5B using the trl-lib/ultrafeedback_binarized preference dataset.
The base and aligned models are tested on the same prompts, and two beta values
(0.1 and 0.5) are compared.
